## Экспериментальные идеи (изучаются, не утверждены)

### Canvas и взаимодействие
- **Магнитное притягивание** портов: совместимый порт слегка притягивается к курсору/другому порту (spring-анимация). Уже есть подсветка; притягивание — следующий штрих UX.
- **Соединение перетаскиванием от любого порта в обе стороны** (начать с INPUT или с OUTPUT) — сейчас: от OUTPUT к INPUT.
- **Слои/группы** блоков в больших схемах (сворачивание в «папку» с агрегированными портами).
- **Комментарии** на Canvas (закреплённые заметки для команды).
- **Темы Canvas**: тёмная (текущая) / светлая / высококонтрастная.
- **Быстрый запуск блока** по двойному клику (одиночный блок + авто-триггер из симулятора).

### Модели
- **Авто-генерация контракта**: предложить INPUT/OUTPUT модели по «краям» выделенной под-схемы (блоки без входов → INPUT, без выходов → OUTPUT).
- **Типизированные шаблоны моделей** (Order Model, User Model, Payment Model) — стартовые заготовки.
- **Превью модели** в палитре: мини-схема + контракт.
- **Совместимость версий моделей**: вызов модели с `version <= текущей`.

### Telegram / Web
- **Конструктор Inline-клавиатур** визуально (сетка кнопок → JSON).
- **Web: live-превью с двумя «окнами»** — Canvas + страница, синхронизированные (клик по элементу на странице подсвечивает блок).
- **Telegram Mini App (WebApp)** как цель рендеринга Web-страницы.

### Debug и AI
- **BREAKPOINT**: остановить выполнение на узле (кнопка «приоритет» в inspector) — после этапа 2.
- **Таймлайн выполнения**: горизонтальная шкала (Gantt) узлов по времени.
- **AI-диагностика**: «почему схема не сработала» — анализ журнала + подсветка проблемного узла.
- **AI-генерация схемы** из текста: «Создай бота, который получает фото, анализирует и отвечает» → визуальная схема (пользователь подтверждает и правит руками).
- **Исправление ошибок AI**: предложение конкретного изменения (с diff по конфигурации).

### Продукт
- **Командные проекты** (несколько редакторов, live-синхронизация — оптимистичный CRDT для canvas).
- **Marketplace моделей** с рейтингом.
- **Templates**: готовые старты («Помощник с FAQ», «Приём заявок», «Опрос»).
- **Встраивание Canvas** (iframe) в сторонние продукты (белый лейбл).
- **CLI**: экспорт/импорт проектов в CI.

### Производительность
- Web Worker для выполнения тяжёлых схем (UI не блокируется).
- Ленивый рендер рёбер (только видимые + анимированные).
- Сжатие формата (gzip/бинарный) для больших проектов в API-хранилище.
