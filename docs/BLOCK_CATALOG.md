# BLOCK_CATALOG — Каталог деталей NODEZZLE

**Обновлено:** 2026-09-14 (Этап 3). Развивает [BLOCKS.md](BLOCKS.md) в полный
каталог с фактическими статусами. Источник правды о факте — реестр
(`src/blocks/`, `npm test` подсчёт реестра).

## 1. Статусы определений

| Статус | Значение |
|---|---|
| РЕАЛИЗОВАНО | есть исполняемый код (`runtime`), деталь доступна в палитре |
| ПОКРЫТО ТЕСТАМИ | реализовано и непосредственно исполняется автотестами |
| ЗАРЕЗЕРВИРОВАНО | определение и контракт портов зафиксированы, исполнение не реализовано; скрыто из палитры (`available: false`) |
| СЛУЖЕБНОЕ | не в палитре; вставляется особым действием (стикер) |

**Факт на дату:** зарегистрировано **33** определения — **25 в палитре**
(14 из них покрыты исполнением в тестах), **7 зарезервированных**,
**1 служебное** (стикер-заметка). Целевая библиотека Этапа 4 — 16 категорий ×
10+ блоков (160+ определений, [04-BLOCK-LIBRARY.md](agent-plan/04-BLOCK-LIBRARY.md)).
