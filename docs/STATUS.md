## Что уже можно делать в продукте

- Создавать проекты (Телеграм / Веб / Телеграм+Веб / Пустой), загружать демо.
- Собирать схемы: библиотека, умные соединения, быстрая вставка, группы,
  стикеры, инспектор, контекстное меню, режим фокуса, поиск по схеме.
- Читать компактные детали: две колонки портов, типы-глифы и полные подсказки.
- Создавать модели из выделения, спускаться внутрь моделей, вызывать модели
  из моделей.
- Запускать схемы симулятором; смотреть журнал, значения портов, историю;
  предпросмотр телефона с Telegram и веб-превью (события запускают схему).
- Отмена/повтор, автосохранение в LocalStorage.
- Серверная часть: аккаунты и сессии, рабочие пространства, проекты с
  версиями и публикацией (LIVE), секреты с шифрованием, исполнение схем
  через АПИ и Телеграм-вебхук, журналы исполнения и журнал действий
  (русский интерфейс истории и аудита).
- Подключение Телеграм-бота через интерфейс (токен — только в
  зашифрованном хранилище сервера); симулятор работает без токена.
- Обучение в Академии: 12 уроков базового курса (детали,
  соединения, запуск, условия, конвертеры, бот в симуляторе, команды,
  веб-события, модели); шаги проверяются автоматически; уроки идут в
  отдельном учебном проекте-песочнице (теория — без проекта); краткие инструкции с раскрываемой теорией и сворачиваемая карточка; справочник всех деталей из реестра с честными статусами; поиск помощи по урокам и деталям, контекстные подсказки на Canvas; глоссарий; онбординг первого запуска ([ACADEMY.md](ACADEMY.md)).
- Локальный запуск на своём компьютере: двойной клик
  `start-nodezzle.bat` (Windows) или `npm run dev:all`.

## Чего ещё нет (честно)

- Продакшн-деплоя: локальная среда разработки — это не продакшн
  (секрет сессии временный; деплой — отдельная задача по команде
  владельца).
- Исполнения для 80 запланированных деталей библиотеки (контракты
  зафиксированы; реальное исполнение — следующие этапы) и веб-элементов
  оформления в рендеринге ([BLOCK_CATALOG.md](BLOCK_CATALOG.md)).
