## Этап 0 — Фундамент ✅ (этот коммит)

Цель: техническая основа + документация. **Без полной реализации NODEZZLE.**

- [x] Аналитика репозитория; структура проекта
- [x] Стек: Vite + React 19 + TypeScript + @xyflow/react + Zustand + i18next + Tailwind 4 + Zod + Vitest (обоснование — DECISIONS.md)
- [x] Русская документация: CONCEPT, ARCHITECTURE, BLOCKS, MODELS, TELEGRAM, WEB, UI, PROJECT_FORMAT, ROADMAP, IDEAS, DECISIONS, AGENTS.md, README, CHANGELOG
- [x] Ядро: Block Definition, BlockRegistry, система типов, совместимость портов
- [x] Runtime: живое выполнение, состояния, pull-источники, циклы, отмена, модели внутри моделей
- [x] 24 блока (18 в палитре + 6 зарезервированных)
- [x] Canvas: палитра, drag&drop, умные соединения, undo/redo, minimap, autosave, inspector
- [x] Debug: симулятор, чат (outbox), журнал, история
- [x] Демонстрационный проект (Telegram → Модель → Telegram)
- [x] Тесты ядра (34 unit-теста), typecheck, build
