# DESIGN_SYSTEM — Дизайн-система NODEZZLE

**Статус:** РЕАЛИЗОВАНО (фактическое состояние темы описано по коду;
источник правды — `src/styles/globals.css` и `src/features/canvas/categoryColors.ts`).

Стиль: **Premium Dark UI** — glassmorphism, aurora-градиенты, неоновые акценты.
Принцип-ограничитель: **читаемость Canvas важнее эффектов** — декор не мешает
чтению схемы.

## 6. Деталь на холсте

Минимальная ширина 208 px; скругление 14; тёмный градиент фона; строки портов
по 26 px; подпись порта 11 px + глиф типа; выделение — циановая рамка и тень;
подсветка при наведении. Рамки групп — пунктир `rgba(148,163,184,0.4)` с ярлыком.

## 7. Анимации

Реализованы чистым CSS (без библиотек анимации — ADR-005):
`node-pulse` (выполняющийся узел), `dashdraw` (поток данных по ребру),
`dot-blink` (точка статуса), `bubble-in` (пузырь чата), `hero-glow`/`hero-dash`
(лендинг). Правило: анимации подчёркивают состояние, а не отвлекают;
переключатель «эффекты» в тулбаре отключает анимацию выполнения.

## 8. Правила развития темы

1. Новые цвета/токены — только в `@theme` `globals.css`; не хардкодить палитру в компонентах без причины.
2. Новые пользовательские классы — в `globals.css` с комментарием.
3. Состояния компонентов описывать семантически (успех/ошибка/выполняется), не произвольными цветами.
4. Светлая/высококонтрастная темы — экспериментальная идея ([IDEAS.md](IDEAS.md)); текущая тема — только тёмная.
