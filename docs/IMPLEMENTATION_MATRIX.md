в тестах), 80 запланированных (скрыты), 1 служебный стикер. Полная таблица —
[BLOCK_CATALOG.md](BLOCK_CATALOG.md). Целевая библиотека Этапа 4: 16 категорий

аудит (часть H) подтвердил порог 16 × 10+ автотестом каталога.
