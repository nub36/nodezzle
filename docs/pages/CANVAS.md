# Страница: Холст (Редактор)

**Маршрут:** `/projects/:projectId` · **Компоненты:** `src/features/canvas/*`
**Статус:** РЕАЛИЗОВАНО, ключевые механики ПОКРЫТЫ ТЕСТАМИ · **Продакшн-статус:** не развёрнуто

Основной экран сборки; результат Этапов 1–2. Спецификация механик —
[02-CANVAS-UI.md](../agent-plan/02-CANVAS-UI.md); детали блоков —
[BLOCK_CATALOG.md](../BLOCK_CATALOG.md).

## Состав (факт)
- **Холст** (React Flow): детали, рёбра, миникарта, контролы, фон-точки.
- **Тулбар**: имя проекта, статус автосохранения, масштаб, поиск по схеме,
  Черновик/Живой, эффекты, Запустить/Стоп, отмена/повтор, панель отладки.
- **Библиотека деталей**: вкладки «Основные/Все/Избранное/Недавние/Мои детали/
  Мои модели», поиск, звёздочки, категории с цветами/иконками.
- **Инспектор**: деталь / соединение / холст; контракт «Вызова модели».
- **Контекстное меню**: дублировать, копировать, отключить связи, следовать по
  связи, заметка, «Создать модель из выделенного», сгруппировать/разгруппировать, удалить.
- **Быстрая вставка**: стартовые детали на пустой схеме; совместимые детали при
  отпускании связи на пустом месте.
- **Группы** — рамки с ярлыком (выделение/перетаскивание/переименование).
- **Спуск внутрь модели** + хлебные крошки `Проект › Модели › Имя`.
- **Режим фокуса** (приглушение всего, кроме выбранной под-схемы).
- **Стикеры-заметки** (комментарии, не участвуют в выполнении).
- **Панель отладки** — см. [TELEGRAM_PREVIEW.md](TELEGRAM_PREVIEW.md),
  [WEB_PREVIEW.md](WEB_PREVIEW.md) и [../IMPLEMENTATION_MATRIX.md](../IMPLEMENTATION_MATRIX.md) §4.

## Состояния
| Состояние | Поведение |
|---|---|
| Загрузка проекта | «Загрузка…» |
| Пустая схема | стартовые детали быстрой вставки |
| Перетаскивание связи | подсветка совместимых портов, приглушение несовместимых |
| Выполнение | пульс узлов, поток по рёбрам, чип статуса |
| Автосохранение | «Сохранение…» → «Сохранено» |

## Данные
`NodezzleProject` → `canvas` (и `canvas` моделей при спуске внутрь);
состояние редактора — `project-store` (узлы/рёбра/группы/история),
состояние выполнения — `execution-store`. Автосохранение: 900 мс + сброс при
закрытии вкладки. История: до 100 снапшотов (узлы/рёбра/группы).

## Действия пользователя
Вставка/перемещение/соединение деталей, выделение рамкой, группировка,
создание модели из выделения, спуск в модель, запуск/остановка, поиск по
схеме, отмена/повтор, дублирование/копирование/вставка.
