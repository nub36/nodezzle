# Страница: Предпросмотр телефона с Telegram (Telegram Preview)

**Где:** вкладка «Телефон» панели отладки на холсте · **Компонент:**
`src/features/canvas/PhonePreview.tsx` · **Статус:** РЕАЛИЗОВАНО (симуляция) ·
**Продакшн-статус:** не развёрнуто

## Назначение
Показать, как бот выглядит и отвечает в телефоне пользователя, без реального
транспорта. Тот же запуск схемы, что в «Чате» и «Журнале».

## Состав (факт)
- Рамка телефона со статус-баром и шапкой бота.
- Пузыри сообщений: эхо входящего сообщения пользователя (из Симулятора) и
  ответы бота из `outbox` выполнения; фото — плейсхолдер с подписью.
- Автопрокрутка к последнему сообщению.

## Состояния
| Состояние | Поведение |
|---|---|
| Пусто | подсказка запустить схему |
| Выполнение | появление пузырей по мере отправки |
| Ошибка схемы | статус в шапке панели, журнал во вкладке «Журнал» |

## Данные
`execution-store`: `chatEcho` (входящее) и `outbox` (сообщения бота).
Транспорт — симуляция: отправки `Отправить сообщение/фото` попадают в `outbox`,
реального токена нет и не будет во frontend ([TELEGRAM](../TELEGRAM.md),
[SECURITY](../SECURITY.md)).

## Действия пользователя
Запустить схему из Симулятора (источник «Телеграм» + текст/команда),
остановить, сбросить.

## Запланировано
- Реальный транспорт: вебхук → рантайм → Bot API (только сервер;
  [ROADMAP](../ROADMAP.md), этап 2).
- Статусы бота (онлайн/офлайн), журнал отправки в реальном времени.
- Поддерживаемые сейчас типы сообщений: текст и фото; прочие — по мере
  развития блоков Телеграм ([BLOCK_CATALOG](../BLOCK_CATALOG.md) §6).
