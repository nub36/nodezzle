# Страница: Авторизация (Аутентификация)

**Маршрут:** нет (появится вместе с backend) · **Статус:** ЗАПЛАНИРОВАНО
**Продакшн-статус:** не существует

## Назначение
Вход, регистрация и восстановление пароля — на русском языке. Появляется
вместе с серверной частью и базой данных ([DATABASE.md](../DATABASE.md) §2.1).

## Спецификация (целевое поведение)

### Экраны
1. **Вход** — электронная почта + пароль; ошибки валидации на русском.
2. **Регистрация** — имя, почта, пароль (с подтверждением); создание рабочего
   пространства.
3. **Восстановление пароля** — запрос по почте, ссылка с одноразовым токеном.

### Состояния
| Состояние | Поведение |
|---|---|
| Пустая форма | подсказки у полей |
| Ошибка ввода | русские сообщения об ошибках под полями |
| Запрос выполняется | блокировка кнопки, индикатор |
| Успех | переход на Дашборд (вход) / письмо (восстановление) |

### Данные и безопасность
- Пароли — только хеши на сервере ([SECURITY.md](../SECURITY.md) §3.1).
- Сессия — защищённый механизм (будет определён с backend).
- До появления сервера страница не реализуется: сейчас продукт локальный.
