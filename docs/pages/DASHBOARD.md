# Страница: Дашборд (Проекты)

**Маршрут:** `/dashboard` · **Компонент:** `src/features/dashboard/DashboardPage.tsx`
**Статус:** РЕАЛИЗОВАНО · **Продакшн-статус:** не развёрнуто

## Назначение
Список проектов пользователя и точки входа в создание/загрузку.

## Состав (факт)
- Карточки проектов: имя, тип, дата изменения; открытие в холсте.
- Создание проекта: выбор типа — Телеграм / Веб / Телеграм+Веб / Пустой
  (имена генерируются по-русски: «Телеграм-бот 1» и т. п.).
- «Загрузить пример: Telegram-бот» — демо-проект `demo_telegram_bot`
  (триггер → конвертер → модель «Приветствие» → конвертер → отправка).
- Удаление проекта (с подтверждением).

## Состояния
| Состояние | Поведение |
|---|---|
| Загрузка | индикатор «Загрузка…» |
| Пусто | предложение создать проект или загрузить пример |
| Список | карточки с переходом в холст |

## Данные
`ProjectStorage.list()` → краткие описания (`id, name, kind, updatedAt`);
создание/удаление — через тот же интерфейс. Сейчас — LocalStorage
([DATABASE.md](../DATABASE.md)); с появлением сервера список станет серверным.

## Действия пользователя
Создать проект, открыть проект, удалить проект, загрузить демо.

## i18n
Неймспейс `dashboard.*` (включая `dashboard.names.<kind>`).

## Запланировано
- Рабочие пространства и командные проекты (после аутентификации).
- Шаблоны проектов («Помощник с FAQ», «Приём заявок», «Опрос» — [IDEAS.md](../IDEAS.md)).
- Сортировка/фильтры/поиск при росте числа проектов.
