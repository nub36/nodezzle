# Страница: Проект (настройки конкретного проекта)

**Маршрут:** отдельного маршрута пока нет — настройки доступны на холсте
**Статус:** ЧАСТИЧНО РЕАЛИЗОВАНО (инспектор холста) · **Продакшн-статус:** не развёрнуто

## Назначение
Свойства конкретного проекта: имя, тип, переменные, (в будущем — версии).

## Что реализовано (факт)
- **Имя проекта** — редактируется в тулбаре холста.
- **Инспектор холста** (ничего не выбрано): свойства проекта, список
  переменных, сводка схемы.
- **Тип проекта** (`kind`) выбирается при создании на Дашборде; смена типа
  существующего проекта сейчас не реализована.
- **Поле `variables[]`** существует в формате проекта
  (`{ id, name, type, value, scope: 'project' }`), но исполняемых блоков
  переменных пока нет — они зарезервированы (`available: false`,
  [BLOCK_CATALOG.md](../BLOCK_CATALOG.md) §11).

## Что запланировано (отдельная страница/панель проекта)
- Полноценное редактирование переменных (создание/типы/значения) и их
  использование в схемах.
- Версии проекта: снапшоты, сравнение, откат ([DATABASE.md](../DATABASE.md) §2.1).
- Публикация версии ([ROADMAP](../ROADMAP.md)).
- Экспорт/импорт проекта (JSON).
- Смена типа проекта с проверкой схемы.

## Состояния (целевые)
| Состояние | Поведение |
|---|---|
| Просмотр | сводка: тип, число деталей/моделей, обновлено |
| Редактирование имени | инлайн, автосохранение |
| Версии | список снапшотов, восстановление с подтверждением |

## i18n
Существующие ключи `canvas.inspector.canvas.*`; новые ключи раздела проекта —
при реализации.
