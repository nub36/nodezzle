# Страница: Предпросмотр веба (Web Preview)

**Где:** вкладка «Веб» панели отладки на холсте · **Компоненты:**
`src/features/canvas/WebPreview.tsx`, `web-preview-utils.ts` ·
**Статус:** РЕАЛИЗОВАНО (первая версия), ПОКРЫТО ТЕСТАМИ (запуск событиями) ·
**Продакшн-статус:** не развёрнуто

## Назначение
Живой предпросмотр веб-страницы, собранной из веб-деталей схемы; действия в
превью запускают схему настоящими веб-событиями (тот же механизм, что у
Симулятора — [WEB](../WEB.md)).

## Состав (факт)
- Окно браузера: адресная строка (имя проекта + `.nodezzle.app`), кнопки окна,
  перезагрузка.
- Содержимое страницы собирается из веб-деталей активного холста:
  - `Страница` (`web.page`) — заголовок страницы; событие загрузки при
    открытии вкладки и по перезагрузке;
  - `Кнопка` (`web.button`) — кнопка; клик запускает схему событием
    `{ event: 'button_click', button, at }`;
  - `Форма` (`web.form`) — карточка формы с JSON-значениями; отправка
    запускает схему `{ event: 'form_submit', values, at }`.
- Чистый разбор деталей — `collectWebElements()` (TESTED).

## Состояния
| Состояние | Поведение |
|---|---|
| Нет веб-деталей | честная пустая подсказка, что добавить |
| Выполнение | кнопки блокируются, чип статуса последнего события |
| Ошибка схемы | статус «Ошибка», детали — во вкладках «Журнал»/«Порты» |

## Данные
Узлы активного холста + реестр блоков; запуск — `fireWebTrigger()` стора
выполнения (источник `web`, TESTED). События подходят всем веб-триггерам
(`matches` по источнику).

## Честные пределы версии
- Страница собирается только из существующих веб-деталей (триггеров).
  Элементы оформления (текст, поля, картинки, окна) появятся с библиотекой
  веб-элементов на Этапе 4 ([04](../agent-plan/04-BLOCK-LIBRARY.md), [WEB](../WEB.md)).
- Событие запускает все веб-триггеры холста; маршрутизация по типу события —
  вместе с развитием веб-блоков.

## Запланировано
- Полный рендеринг: PAGE/SECTION/GRID/TEXT/IMAGE/BUTTON/INPUT/FORM/MODAL…
- «Два окна»: холст + страница с подсветкой блока по клику ([IDEAS](../IDEAS.md)).
- Цель рендеринга — в том числе Telegram Mini App (WebApp).
