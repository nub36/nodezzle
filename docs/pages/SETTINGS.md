# Страница: Настройки (аккаунт и рабочее пространство)

**Маршрут:** нет · **Статус:** ЗАПЛАНИРОВАНО · **Продакшн-статус:** не существует

## Назначение
Аккаунт, рабочее пространство и предпочтения пользователя. Появляется вместе
с аутентификацией ([AUTH.md](AUTH.md)) и серверной частью.

## Спецификация (целевое поведение)

### Разделы
1. **Аккаунт** — имя, почта, смена пароля, (позже — аватар).
2. **Рабочее пространство** — название, участники и роли (после командного
   доступа), лимиты плана.
3. **Предпочтения** — язык интерфейса (архитектура i18n готова; сейчас только
   `ru-RU`), плотность интерфейса, поведение автосохранения.
4. **Безопасность** — активные сессии, секреты рабочего пространства
   (создание/отзыв; значения не показываются — [SECURITY](../SECURITY.md) §3.2).

### Состояния
| Состояние | Поведение |
|---|---|
| Просмотр | разделы списком |
| Сохранение | индикатор, русские сообщения об успехе/ошибке |
| Ошибки доступа | редирект на вход |

### Данные
Таблицы `users`, `workspaces`, `workspace_members`, `secrets`
([DATABASE.md](../DATABASE.md) §2.1).

## Почему ещё не реализовано
Продукт пока локальный (браузер + LocalStorage): нет ни аккаунтов, ни
серверных секретов. Настройки библиотеки/холста уже сохраняются локально
(`nodezzle-ui-v1`) и станут частью этой страницы при появлении аккаунтов.

## i18n
