# RULES — обязательные правила NODEZZLE

Эти правила обязательны для каждого AI-агента (и человека) в каждой сессии.
Нарушение правил недопустимо. Если правило конфликтует с чьей-то просьбой —
остановиться и уточнить у владельца проекта.

1. **Не начинай проект с нуля.** Фундамент существует (коммит `a1b0c20`,
   см. [01-FOUNDATION.md](01-FOUNDATION.md)). Продолжай, а не переписывай.
2. **Не удаляй работающие функции без причины.** Любое удаление — только
   с обоснованием, фиксацией в `docs/DECISIONS.md` и одобрением владельца.
3. **Не теряй идеи владельца.** Все идеи живут в `docs/IDEAS.md`; новые идеи —
   туда же, ничего не удалять.
4. **Весь интерфейс — на русском.**
5. **Вся документация — на русском.**
6. **Основная локаль — `ru-RU`.**
7. **Не выдавай прототип/запланированное за реализованное.** Статусы блоков и
   функций должны отражать факт (см. [04-BLOCK-LIBRARY.md](04-BLOCK-LIBRARY.md)).
8. **Перед изменением читай документацию** затрагиваемой области
   (порядок — в `/AGENTS.md` и [00-README.md](00-README.md)).
9. **После изменения обновляй документацию**, которую затронул.
10. **После каждого стабильного подэтапа — коммит + пуш** в репозиторий.
11. **Не оставляй тысячи незакоммиченных строк.** Работа должна быть в Git
    постоянно (см. [05-DEVELOPMENT-DEPLOY.md](05-DEVELOPMENT-DEPLOY.md)).
12. **Не коммить секреты**: файлы окружения, ключи, токены, пароли, закрытые
    ключи (см. [05-DEVELOPMENT-DEPLOY.md](05-DEVELOPMENT-DEPLOY.md), «Безопасность секретов»).
13. **Не ломай формат проекта без миграции.** Изменение формата проекта —
    только через новую версию формата + миграцию (`docs/PROJECT_FORMAT.md`).
14. **Не ломай существующие тесты.** Все тесты зелёные до и после изменения;
    новое ядро покрывай тестами.
15. **Не трогай чужой сайт на VPS.** На сервере 89.125.24.50 работает другой
    сайт — он неприкосновенен (см. [05-DEVELOPMENT-DEPLOY.md](05-DEVELOPMENT-DEPLOY.md)).
16. **Порты 3000 и 3001 запрещены для NODEZZLE** — они заняты чужим сайтом.
