## Известные проблемы

1. **`main` не содержит фундамент и план.** Актуальная работа живёт в ветке
   `arena/01a09bee-nodezzle` (фундамент `a1b0c20` есть также в
   `arena/01a09a3f-nodezzle` и `arena/01a09b67-nodezzle`). В `main` пока только
   `f0bec2f` (README). Нужно влить актуальную ветку в `main` через пул-реквест.
2. **Телеграм — только симуляция**: реального транспорта бота нет
   (это этап 2 дорожной карты `docs/ROADMAP.md`).
3. **Хранилище — только LocalStorage**: серверного хранилища и базы данных нет.
4. **Запланированные детали без исполнения** — 80 определений с
   `available: false` (заготовки библиотеки Этапа 4 в
   `src/blocks/**`); скрыты из палитры, это ожидаемо: контракты
   зафиксированы, исполнение — следующие этапы.
5. **Нет продакшн-развёртывания и нет серверной части** (см. [05-DEVELOPMENT-DEPLOY.md](05-DEVELOPMENT-DEPLOY.md)).
6. Сборка выдаёт предупреждение о размере фрагмента больше 500 килобайт —
   не ошибка, учесть при развитии интерфейса.
