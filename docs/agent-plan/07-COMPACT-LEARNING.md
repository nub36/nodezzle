# 07 — Компактный Canvas и учебные материалы

Запрос владельца от 2026-09-14: продолжить проект, переработать обучение,
сделать блоки компактными. Этапы 1–5 не начинаем заново. Это отдельное
улучшение существующего интерфейса; продакшн-деплой не входит.

## A. Компактная подача — выполнено (0.5.29)

- [x] Детали: две колонки портов, ширина 240 px, строки 24 px;
  типы показаны глифами, полные названия доступны при наведении.
- [x] Исправлена привязка маркера к своей строке. Каждый порт доступен
  отдельно, в том числе несколько выходов одной детали.
- [x] Автовписывание первой детали ограничено масштабом 100%, ручной
  масштаб до 220% сохранён.
- [x] Академия: компактная сетка разделов, описания всех 12 уроков короче.
- [x] Краткая инструкция + раскрываемая теория (`detailsKey`), план
  урока в раскрываемых строках, запуск над планом.
- [x] Сворачиваемая карточка шага 304 px; не закрывает инспектор,
  когда шаг просит изучить его. Узкий экран проверен отдельно.
- [x] Исправлен пропуск практического выбора детали из-за автовыделения
  при вставке. Снятие выделения — только в песочнице на входе в шаг.
- [x] Урок публикации отделяет серверную публикацию через API от
  визуального переключателя режима; рабочий проект открывать не нужно.
- [x] Проверки: 395 unit/integration, 11 браузерных E2E, typecheck, build.

## Следующие небольшие подэтапы

1. **B — Полное браузерное прохождение курса.** Сейчас все 12 уроков
   покрыты статическим валидатором и обходом снимков, но не целиком E2E.
   Добавлять сценарии по одному: сначала конвертеры и бот-эхо, затем
   условия, команды, веб, модели, отладка. Проверять фактические значения,
   настройки и порты, а не только продвижение индекса шага.
2. **C — Вставка деталей без наложений.** Клик в библиотеке пока помещает
   детали в центр; при нескольких вставках их приходится раздвигать.
   Предложить поиск ближайшего свободного места с учётом размеров,
   масштаба и панелей; не менять вручную заданные позиции существующих узлов.

## Условия готовности каждого подэтапа

ACADEMY_QA и CHANGELOG. Коммит и push — только в рабочую ветку сессии.
