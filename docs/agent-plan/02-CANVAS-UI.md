(см. [05-DEVELOPMENT-DEPLOY.md](05-DEVELOPMENT-DEPLOY.md)).

## A. UI Store + Библиотека v2

Отдельный UI-store (Zustand) для состояния интерфейса и новая библиотека деталей:

- **Поиск** по названию/описанию/ключевым словам.
- **Избранное** — закреплённые пользователем детали.
- **Недавние** — последние использованные детали.
- **Мои детали** — пользовательские/локальные детали.
- **Мои модели** — созданные пользователем модели (вызываются как детали).
- **Основные / Все** — режимы отображения: базовый набор и полная библиотека.
- **Категории** — дерево категорий с цветом/иконками (развитие текущей палитры).

## B. Тулбар (панель инструментов)

- Название проекта (редактируемое).
- **Индикатор автосохранения** (состояние: сохранено / сохраняется / ошибка).
- **Undo/Redo** (с индикацией доступности).
- **Масштаб** (зум: −, %, +, «вписать»).
- **Поиск** по схеме.
- **Запуск** (Старт/Стоп выполнения).
- Переключатель **Черновик / Живой режим** (Draft / Live).
- Переключатель визуальных **эффектов** (частицы, свечение).

## C. Блок / Порт / Соединение (живой UI)

- **«Живые» детали**: детали визуально ощущаются как физические элементы пазла
  (свечение при активности, тени, аккуратные состояния).
- **Визуальные типы портов**: форма/цвет/иконка по типу данных
  (текст, число, логическое, JSON, файл, событие, ошибка и т. д.).
- **Совместимость в UI**: подсветка совместимых портов при протягивании связи,
  запрет несовместимых соединений (уже частично есть в фундаменте — развить).
- **Анимация выполнения**: данные «текут» по соединениям во время работы схемы;
  состояния блоков (ожидание / выполняется / успех / ошибка).

## D. Быстрая вставка (Quick Insert)

Сценарий: на пустом Canvas или от свободного порта —

1. предложить блоки **выходных** действий (ОТПРАВКА/вывод) либо продолжить от порта;
2. на **пустом Canvas** — предложить стартовые блоки;
3. показать только **совместимые блоки** (по типу порта/контекста);
4. создать выбранный блок;
5. **автоматически подключить** его к исходному порту/контексту.

## E. Инспектор (правая панель)

Контекстный инспектор в зависимости от выбора:

- **Блок** — конфигурация, результаты последнего выполнения, ошибки.
- **Соединение** — типы портов, данные последнего прохождения, удалить/заменить.
- **Модель** — контракт (входы/выходы/ошибки), версия, открыть внутрь.
- **Холст (ничего не выбрано)** — свойства проекта, переменные, сводка.
- **Веб-элемент** — свойства веб-детали (текст, стили, события).

## F. Контекст и фокус

- **Контекстное меню** (правый клик): дублировать, удалить, отключить,
  превратить в модель и т. п.
- **Режим фокуса** — приглушить всё, кроме выбранной под-схемы.
- **Следование связям (Follow Connections)** — навигация по цепи входов/выходов.
- **Стикеры-заметки** — закреплённые комментарии на Canvas.
- **Группы** — визуальная группировка блоков (рамка/папка). *(выполнено,
  подэтап F часть 2, v0.2.9: опциональное поле `groups` в формате, рамки,
  группировка/разгруппировка через контекстное меню, история, сохранение)*

## G. Модели (создание из Canvas)

1. **Выделение блоков** пользователем.
2. **«Создать модель»** из выделенной под-схемы.
3. Определение **внешних портов**: какие связи становятся
   **ВХОД (INPUT)**, **ВЫХОД (OUTPUT)**, **ОШИБКА (ERROR)** модели.
4. **Контракт модели (Model Contract)** — именованные типизированные порты.
5. **Узел модели (Model Node)** — модель появляется в библиотеке («Мои модели»)
   и вызывается как одна деталь.

База уже есть в ядре (контракты, `Вход модели`/`Выход модели`, `Вызов модели`,
`executeModel`) — этап добавляет полноценный UI создания и управления.

**Выполнено (подэтап G, 2026-09-14, v0.2.8):** пункты 1–4 реализованы как
«выделить → контекстное меню „Создать модель из выделенного“ → диалог с
автоопределением контракта → модель в списке моделей»; пункт 5 работает —
модель появляется в «Мои модели» и вставляется «Вызовом модели». Граничные
связи увязаны конвертерами «В объект»/«Из объекта». Ограничения версии: один
внешний вход, без внешних связей-событий и без триггеров в выделении.

## H. Спуск внутрь (Drill Down)

- **Двойной клик** по узлу модели → открывается её **внутренний Canvas**.
- **Хлебные крошки (Breadcrumb)**: `Проект > Модели > Заказы > Оплата`.
- Возврат на любой уровень вверх без потери состояния.

## I. Предпросмотр и отладка

- **Предпросмотр телефона с Telegram (Telegram Phone Preview)** — как бот

## Зафиксированные дополнительные идеи этапа

Обязательный список можно выполнять постепенно, но эти возможности **зафиксированы
как часть видения** — их нельзя терять (см. также `docs/IDEAS.md`):

- **Портал (Portal)** — мгновенный перенос данных между удалёнными частями схемы.
- **Рентген модели (Model X-Ray)** — просмотр внутренностей модели без входа внутрь
  (полупрозрачный/свёрнутый режим).
- **Семантический зум (Semantic Zoom)** — на разных масштабах разный уровень
  детализации (схема → группы → подписи).
- **Автораскладка (Auto Organize)** — автоматическое аккуратное расположение блоков.
- **Динамические порты (Dynamic Ports)** — порты, добавляемые по конфигурации
  (например, список ключей объекта).
- **Сохранить как деталь (Save as Piece)** — переиспользование фрагмента схемы.
- **Трассировка выполнения (Execution Trace)** — пошаговый след выполнения схемы.
- **Основа повтора (Replay foundation)** — воспроизведение прошедшего выполнения.
- **Черновик / Живой режим (Draft/Live)** — черновик схемы против «живой» версии.
- **Публикация (Publish)** — публикация версии проекта/бота.
- **История версий (Version History)** — снапшоты и откат.
