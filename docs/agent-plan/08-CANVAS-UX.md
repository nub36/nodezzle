Продолжаем существующий Canvas; серверное сохранение и продакшн-деплой
в этот этап не входят. План 07 не переоткрывается.

## Границы

В A не вводятся глобальная раскладка, перенос определений моделей между
проектами или копирование визуальных рамок групп. Внутренний буфер деталей
не заменяет системный буфер текста; сочетания в полях ввода не перехватываем.
После каждого стабильного подэтапа: typecheck, test, build, E2E, документация,
русский commit и push только в рабочую ветку сессии.
