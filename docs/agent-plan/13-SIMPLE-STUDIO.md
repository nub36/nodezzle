## Решение и границы среза

Название «Простой режим». Карточки отображают реальные nodes, связи — реальные
edges с исходными портами. Это не линейная копия графа: связи явно показываются,
порядок карточек не выдаётся за порядок исполнения. Никакой перезаписи координат
при просмотре. Метаданные, модели и группы не удаляются.

Начальный набор намеренно мал: Telegram — событие сообщения, команда, отправка
ответа; core.text доступен дополнительно для уже составленных цепочек. Web —
web.text и core.text. Пустая схема — core.text, далее переход в PRO для сложной
композиции. Presentation задаёт только ID/подписи/группировку, не definitions.

Контекстное «Что сделать дальше?» у события добавляет обычный ответ и реальный
провод chat_id → chat_id. Текст вводится прямо в карточке. Уже подключённый
текст явно подписан и не заменяется настройкой. Возможность выбрать событие
для несвязанного ответа нужна для исправления/старых проектов.

Неподдержанные блоки, связи, поля конфигурации, модели, группы и смешанная схема:
безопасное представление только для чтения, полный список деталей и связей,
раскрываемые данные; редактирование и выполнение — PRO. Не интерпретировать
неизвестные конструкции как простой линейный сценарий. Поддержанные старые
схемы остаются редактируемыми. F5 и переключение сохраняют тот же projectId,
никакой миграции/конвертации. При ошибке сохранения переход режима не выполнять.

Новый код нужен только для композиции простого экрана, отбора/проверки
представимости, доступных форм, выбора следующего действия и переключения режима.
Один Project Format v1, BlockRegistry, Runtime, project-store, ProjectStorage.
Тарифы, paywall, новые рецепты/блоки и VPS не входят в работу.

## Приёмка

Unit: реальный runtime с фиксированным текстом/приоритетом провода/пустым входом;
curation и строгие границы редактирования. E2E через UI без подготовки JSON:
создание → событие → ответ → текст → проверка → телефон → PRO → Simple;
F5, undo/redo, неподдержанный блок без потери данных, старый проект, 390 px,
ошибка обязательной настройки/исправление. Полный прежний набор, types/build.
